# Brief templates

## Product launch (20s)
Assets: visit the site, take real screenshots with Playwright, real logo, colors and fonts. List them before animating.
Story, one beat each, 2 to 4 seconds:
1. Hook: the problem in 5 words of huge kinetic type.
2. The product appears, its UI assembles piece by piece.
3. Three features, each a UI moment with a cursor doing a real action.
4. One real metric that proves it works.
5. Logo lockup and call to action.
Sound: original music near 120 BPM, UI clicks and whooshes on the beat.

## State list (looping UI film)
One container never cuts. Every state is the same element changing size, radius and fill while content swaps behind a short blur. A cursor drives each change. Warm neutral canvas, one accent, springs with at most a tiny overshoot.
Ask for: product, 8 to 12 UI states, the real data in each, brand colors, fonts, a track near 120 BPM.
Example chain: logo, button, typed email field, loader, success check, dashboard card, chart drawing itself, tooltip, command menu, notification, logo.
Text inside a morphing container enters after the morph starts and leaves before the next one. The last frame equals the first, cursor position and speed included.

## Long film (overnight)
Sections: the film in one line, references and inputs, tools and budget, look, beat sheet (hook in the first 2 seconds, a payoff every 3 to 5), deliverables.
Gates, no skipping: style guide and shot list, stills for every shot, low-res rough cut, full animation, polish, sound, final render.
For long films write `docs/ANIMATION_GUIDE.md` first, then split chapters across subagents so they code in one style. Log scores in `docs/review_log.md`.
