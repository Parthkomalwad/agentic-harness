## What this is

This is the toolkit I use every day with Claude Code, published as one plugin marketplace. I add a pack whenever I find something worth keeping: UI that does not look AI-made, deployment and DevOps, architecture, memory, testing, launch.

> **Off means zero.** Every pack except `core` starts off. A pack that is off adds no skills, agents or tokens to a session.

It follows my workflow and changes when that does. Use it, fork it, or take single packs.

## Install

```text
/plugin marketplace add Parthkomalwad/agentic-harness
/plugin install core@agentic-harness
```

Then just say what you are working on. `core` matches it to the right packs and turns them on for that project only:

```text
I need a landing page that does not look AI-made, and a cheap place to host it
```

Cloud sessions and claude.ai work too: see the [guide](docs/guide.md).
